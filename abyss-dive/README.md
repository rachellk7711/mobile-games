# 심연 잠항 (Abyss Dive)

잠수정 한 척으로 수심 0 m에서 챌린저 해연 바닥(10,935 m)까지 내려가는 모바일 로그라이트 슈팅 게임입니다. 깊어질수록 빛이 사라지고, 화면에는 탐조등과 생물 발광만 남습니다.

- **장르**: 생존형 자동 사격 + 레벨업 장비 선택 (뱀서라이크)
- **플레이 시간**: 한 판 약 12~16분 (보스 4종 포함)
- **조작**: 화면을 끌면 플로팅 조이스틱, 오른쪽 아래 버튼은 급가속(순간 무적). PC에서는 WASD/방향키, Space, Esc
- **외부 의존성 없음**: 그래픽은 모두 Canvas 2D 절차 생성, 소리는 모두 WebAudio 합성. 이미지와 사운드 파일이 없습니다 (Google Fonts만 사용).

## 실행

`index.html` 하나로 동작합니다. 브라우저로 열거나 아무 정적 호스팅(GitHub Pages 등)에 올리면 됩니다.

```bash
node build.js          # src/ 를 합쳐 index.html 재생성
```

## 구성

| 파일 | 내용 |
|---|---|
| `src/head.html` | 타이틀, CSS, HUD와 화면(메뉴, 레벨업, 일시정지, 결과, 도감) 마크업 |
| `src/01_util.js` | 수학 함수, 저장소(localStorage), 충돌용 격자 |
| `src/02_audio.js` | WebAudio 효과음, 수심에 따라 어두워지는 배경음 |
| `src/03_gfx.js` | 캔버스, 발광 스프라이트 캐시, 해양 5개 층 팔레트, 배경(빛기둥, 마린 스노우, 고래) |
| `src/04_fx.js` | 파티클 풀, 데미지 숫자, 화면 흔들림 |
| `src/05_player.js` | 잠수정, 무기 5종(작살포, 소나, 드론, 어뢰, 전기 아크), 강화 8종 |
| `src/06_enemies.js` | 심해 생물 8종의 AI, 그리기, 발광 |
| `src/07_boss.js` | 보스 4종(대왕오징어, 초롱아귀, 관해파리 군체, 해연의 군주), 경고 표시가 있는 패턴 |
| `src/085_extras.js` | 심해 도감(실제 생물 정보 12종), 선체 균열, 해저 도달 연출, 조작 안내 |
| `src/08_game.js` | 입력, 게임 루프, 조명(어둠 마스크) 렌더링, HUD, 화면 전환 |

## 게임 디자인 메모

- **해양층**: 표층(0–200 m), 중층(200–1,000), 점심해층(1,000–4,000), 심해저층(4,000–6,000), 초심해층(6,000–10,935). 수압은 수심/10.06 + 1 기압, 수온도 층마다 실제 범위로 표시합니다.
- **어둠과 빛**: 깊을수록 어둠 마스크가 짙어집니다. 잠수정 조명, 탐조등, 드론, 어뢰, 폭발이 어둠을 밝힙니다. 생물의 발광기는 어둠 위에 가산 합성으로 그려서, 깊은 곳에서는 빛만 보고 적을 찾아야 합니다.
- **보스 체력**: 보스가 나타나는 순간 플레이어의 예상 DPS를 계산해 정합니다(최소, 최대 한도 있음). 그래서 빌드가 약하든 강하든 보스전이 대략 40~90초로 유지됩니다.
- **성능**: 발광은 `shadowBlur` 대신 미리 그려 둔 스프라이트를 씁니다. 프레임이 2초 연속 40fps 아래로 떨어지면 자동으로 '절약' 품질로 바뀝니다.

`tests/` 폴더에 있는 스크립트로 확인했습니다. 실행: `cd tests && node t_ui.js` (Chrome 경로는 `cdp.js` 맨 위).

| 가로 스크롤 넘침 없음 | 모든 화면 크기 | 통과 |
