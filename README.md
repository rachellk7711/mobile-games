# 모바일 게임 두 편

| 게임 | 폴더 | 한 줄 소개 |
|---|---|---|
| 심연 잠항 | [`abyss-dive/`](abyss-dive/) | 잠수정으로 챌린저 해연(10,935 m)까지 내려가는 로그라이트 슈팅. 보스 4종 |
| 묵선 | [`mukseon/`](mukseon/) | 수묵화 족자 속 절벽을 먹줄로 오르는 원터치 그래플링. 무한 상승 |

- `index.html`은 두 게임을 고르는 첫 화면입니다. 이 `games/` 폴더를 그대로 GitHub Pages 등에 올리면 `/games/`에서 둘 다 열립니다.
- 각 게임은 `index.html` 파일 하나로 동작하고 빌드 도구가 필요 없습니다. 소스를 고친 뒤에는 각 폴더에서 `node build.js`를 실행하세요.
- 검증 방법과 결과는 각 폴더의 `README.md`에 정리했습니다. 테스트는 `tests/`에 있고 로컬 Chrome이 필요합니다.
