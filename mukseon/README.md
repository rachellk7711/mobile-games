# 묵선 (墨線)

수묵화 족자 속 절벽을 먹줄 하나로 오르는 모바일 원터치 액션 게임입니다. 화면을 누르고 있으면 가장 가까운 매듭에 먹줄을 걸어 끌어올리고, 손을 떼면 그 기세로 날아오릅니다. 아래에서는 먹물이 계속 차오릅니다.

- **장르**: 무한 상승 그래플링 액션 (세로 화면 기준)
- **조작**: 누르고 있기 = 먹줄 걸기와 감기, 떼기 = 놓고 날기. PC에서는 Space / ↑ / W, 일시정지는 Esc
- **목숨**: 낙관 3개. 까마귀, 먹귀신, 번개, 낙석에 맞으면 하나씩 잃습니다. 부적은 한 번 막아 줍니다. 먹물에 빠지면 바로 끝납니다
- **외부 의존성 없음**: 그림은 모두 Canvas 2D 절차 생성, 소리(가야금 느낌의 현, 북, 바람)는 모두 WebAudio 합성. 이미지와 사운드 파일이 없습니다 (Google Fonts만 사용).

## 구역

| 높이 | 구역 | 특징 |
|---|---|---|
| 0 m | 새벽 송림 | 소나무 절벽, 매화 꽃잎 |
| 250 m | 대숲 | 흔들리는 매듭, 붉은 부적 매듭(1초 후 끊어짐), 까마귀, 먹귀신 |
| 700 m | 폭포 계곡 | 떠다니는 매듭, 낙석(경고 표시 후 낙하) |
| 1,300 m | 달밤 | 등불 매듭, 날아다니는 학 매듭, 반딧불 |
| 2,000 m | 뇌우 | 바람, 번개 기둥(붉은 경고 후 낙뢰), 비 |
| 3,000 m | 구름 위 | 해돋이, 운문 구름, 끝없이 계속 |

## 그 밖의 요소

- **판정**: 위로 빠르게 솟구칠 때 놓으면 좋음 / 명필 / 일필휘지. 명필 이상이 이어지면 연속 보너스
- **오늘의 족자**: 날짜로 시드를 정해서 같은 날에는 누구나 같은 지형을 오릅니다
- **낙관첩**: 업적 12개를 붉은 낙관(전각 도장)으로 모읍니다
- **아이템**: 부적(한 번 방어), 학의 깃털(놓을 때 3회 상승 돌풍), 먹(먹물을 아래로 밀어냄)

## 실행

`index.html` 하나로 동작합니다. 브라우저로 열거나 아무 정적 호스팅(GitHub Pages 등)에 올리면 됩니다.

```bash
node build.js          # src/ 를 합쳐 index.html 재생성
```

| 파일 | 내용 |
|---|---|
| `src/head.html` | 타이틀, CSS, HUD, 화면(메뉴, 낙관첩, 일시정지, 결과) |
| `src/01_util.js` | 시드 난수(mulberry32), 값 노이즈, 저장소 |
| `src/02_audio.js` | Karplus–Strong 현 합성(먹줄을 걸 때마다 5음 음계를 오름), 북, 바람, 잔향 |
| `src/03_gfx.js` | 족자 비율 계산, 한지 질감, 먹 번짐 스프라이트, 붓 획(굵기 변화와 비백) |
| `src/04_world.js` | 구역 6개, 지형 생성(모든 줄에 도달 가능한 매듭 보장), 위험 요소 배치 |
| `src/05_bg.js` | 원경 산수와 중경 절벽을 1000단위 조각으로 그려 캐시, 시차 스크롤 |
| `src/06_player.js` | Verlet 물리(1/120초 단위), 먹줄 제약, 붉은 목도리, 위험 요소, 아이템, 먹물 |
| `src/07_fx.js` | 먹 방울, 꽃잎, 붓글씨 판정 글자, 날씨 |
| `src/075_seals.js` | 낙관첩, 족자가 펼쳐지는 시작 연출 |
| `src/08_game.js` | 입력, 게임 루프, 카메라, 먹물 상승, HUD, 화면 전환, 메뉴 뒤 자동 시연 |

## 검증 결과 (헤드리스 Chrome, 자동화)

`tests/` 폴더의 스크립트로 확인했습니다. 실행: `cd tests && node t_ui.js` (Chrome 경로는 `cdp.js` 맨 위).

| 항목 | 방법 | 결과 |
|---|---|---|
| UI 흐름 14개 (시작, 누르고 떼서 오르기, 일시정지, 소리 전환, 재개, 그만두기, 결과, 재시작, 먹물 사망, 메뉴, 오늘의 족자, 같은 시드로 재시작, 기록 저장) | `t_ui.js`, 실제 터치 이벤트 | 390×844, 360×640, 844×390(가로), 1280×800 PC(키보드)에서 모두 통과 |
| 가로 스크롤 넘침 없음 | 모든 화면 크기 | 통과 |
| 낙관첩 (업적 획득, 결과 화면 표시, 도감 반영) | `t_seals.js` | 통과 |
| 지형 도달 가능성 | `t_sim.js` 자동 조종, 매듭 없이 떨어진 시간 측정 | 수천 m 동안 막힌 구간 없음 (매듭을 못 찾고 떨어진 시간 0~1초) |
| 모든 구역 화면 | `t_shots.js`, `screenshots/` | 확인 |
| 난이도 | 위험 요소를 피하지 않는 봇 | 760~1,580 m에서 사망. 사람이 피하면 더 올라갈 수 있는 수준 |
| 프레임 속도 | `t_gpu.js`, Intel Iris Xe GPU, 휴대폰 해상도 dpr 3 | 6개 구역 모두 60 fps |
| 콘솔 오류 | 모든 테스트 | 0건 |

**확인하지 못한 것**: 실제 휴대폰 기기, iOS Safari, 소리를 직접 들어 보는 것(효과음 코드는 오류 없이 실행됨).
